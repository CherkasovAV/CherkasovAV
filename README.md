### 🛠 Чем я могу быть полезен:

*   **🤖 Интеллектуальные базы знаний (RAG):** Создаю системы, которые находят точные ответы в ваших документах с цитатами-источниками. Больше никаких галлюцинаций — только факты из вашей базы.
*   **📄 Автоматизация документов:** Превращаю хаос переписок, транскриптов и брифов в структурированные PDF-отчеты, карточки товаров или технические задания.
*   **💬 Умные Telegram-боты:** Разрабатываю автономных ассистентов с долговременной памятью и инструментами (Agentic Workflow), которые реально решают задачи пользователя.

### 🏆 Ключевые кейсы

#### 📄 AI-Генератор бизнес-отчетов
**Результат:** Время подготовки документа сокращено с **40 минут до 15 секунд**.
*   Автоматический анализ транскриптов диалогов.
*   Генерация брифов на дизайн, отчетов по клиентам и карточек для маркетплейсов.
*   **Стек:** `Python`, `OpenAI API`, `Jinja2`, `WeasyPrint`.

#### 🧠 Корпоративная система знаний (RAG)
**Результат:** Мгновенный поиск по внутренним документам с 100% ссылкой на источник.
*   Векторный поиск по базе документов без «выдумок» ИИ.
*   Система аудита расходов на токены и контроль стоимости запросов.
*   **Стек:** `FastAPI`, `ChromaDB`, `OpenAI Embeddings`, `Docker`.

#### 🤖 Telegram-ассистент с памятью
**Результат:** Бот, который помнит контекст пользователя и автономно использует внешние инструменты.
*   Интеграция векторной памяти для хранения истории и предпочтений.
*   Agentic workflow: бот сам решает, когда вызвать инструмент (погода, поиск, анализ фото).
*   **Стек:** `Haystack 2`, `Pinecone`, `pyTelegramBotAPI`.
